# TCONGS Infotech - Homepage Redesign

A modern, premium homepage redesign for TCONGS Infotech, built with HTML5, CSS3, and Vanilla JavaScript.

## Project Overview

This is a frontend web development assignment for TCONGS Infotech. The project is a complete redesign of the company's homepage, focusing on modern UI/UX principles, responsive design, and accessibility.

## Technology Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom styling with CSS variables
- **Vanilla JavaScript** - Interactive functionality
- **Google Fonts** - Inter font family
- **Font Awesome** - Icon library

## Project Structure

```
tcongs-homepage/
```

## Features

### Sections
1. **Navbar** - Sticky navigation with mobile hamburger menu
2. **Hero** - Premium technology visual with CTAs
3. **Trust Strip** - Core capabilities showcase
4. **About** - Company information with visual elements
5. **Services** - Six service cards with hover effects
6. **Solutions** - Solution categories showcase
7. **Why Choose** - Value proposition highlights
8. **Process** - Six-step timeline
9. **Technology** - Technology capabilities grid
10. **FAQ** - Accordion with keyboard accessibility
11. **Final CTA** - Strong call-to-action section
12. **Contact** - Form with frontend validation
13. **Footer** - Company information and links

### Key Features
- ✅ Fully responsive design (320px to 1920px)
- ✅ Mobile-first approach
- ✅ Smooth scroll navigation
- ✅ FAQ accordion with keyboard support

## How to Run

### Option 1: Using Python
```bash
cd assignment_project
python -m http.server 8000
```

### Option 2: Using PHP
```bash
cd assignment_project
php -S localhost:8000
```

### Option 3: Using Node.js (http-server)
```bash
cd assignment_project
npx http-server -p 8000
```

### Option 4: Using VS Code Live Server
1. Install Live Server extension in VS Code
2. Right-click on `index.html`
3. Select "Open with Live Server"

Then open your browser and navigate to:
```
http://localhost:8000
```
